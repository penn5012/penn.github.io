  filters?: {     product?: string;     version?: string;     documentType?: string;   };   topK?: number; };  type KnowledgeHit = {   content: string;   sourceId: string;   sourceTitle: string;   locator?: string;   score?: number;   metadata?: Record<string, string>; }; ```  下月可以先让 Dify 承担文档导入、切分、向量化和检索，再通过一个只读 `search_knowledge` 工具把检索结果接入本月的 Tool Registry。这样你会清楚看到：  - Dify 负责知识处理和检索； - 工具系统负责校验、权限、超时、结果协议和审计； - LLM 负责结合问题与证据组织回答； - 前端/移动端负责展示答案、引用、来源和反馈。  进入第 5 月前，确保 `search_knowledge` 的结果中保留来源字段。知识库回答如果没有来源，后续很难做引用展示和正确性评测。  ## 十、参考资料  - [OpenAI Function Calling 官方文档](https://developers.openai.com/api/docs/guides/function-calling)：理解工具定义、工具调用、调用结果回传及完整循环。 - [JSON Schema 官方文档](https://json-schema.org/learn/getting-started-step-by-step)：学习对象、必填字段、枚举与约束表达。 - [Zod 官方文档](https://zod.dev/)：TypeScript 运行时校验与类型推导。 - 当前所用后端框架、ORM 和测试框架的官方文档。  学习资料只解决当天遇到的问题。每天先写最小实现，再阅读对应章节并重构；不要把“看完文档”误当作“已经掌握工具系统”。 |
