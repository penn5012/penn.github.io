## 动手任务

1. 生成期间将发送按钮切换为停止按钮。
2. 点击后取消客户端请求，并让服务端感知连接结束。
3. 将消息标记为 `cancelled`，保留已生成内容。
4. 防止取消后到达的迟发事件污染下一次请求。
